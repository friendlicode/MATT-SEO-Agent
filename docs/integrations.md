# Integrations

The agent is designed around four tools.

## Codex

Codex is the operator. It reads the repo, follows the skill, calls available tools, writes deliverables, and can help create issues or pull requests.

Helpful official docs:

- Codex docs index: https://learn.chatgpt.com/docs
- Skills: https://developers.openai.com/api/docs/guides/tools-skills
- MCP servers: https://developers.openai.com/api/docs/guides/tools-connectors-mcp
- Codex GitHub integration: https://learn.chatgpt.com/docs

## Google Search Console

GSC is the source of truth for actual organic search performance.

Use it for:

- Queries
- Pages
- Clicks
- Impressions
- CTR
- Average position
- Date comparisons
- Indexing and sitemap checks

Helpful official docs:

- Search Analytics query method: https://developers.google.com/webmaster-tools/v1/searchanalytics/query
- Query Search Analytics guide: https://developers.google.com/webmaster-tools/v1/how-tos/search_analytics

## DataForSEO/Data4SEO MCP

DataForSEO adds market, competitor, keyword, and SERP context.

Use it for:

- Keyword overview
- Keyword suggestions
- Keyword difficulty
- Search intent
- Ranked keywords
- Competitor domains
- Domain intersections
- Live SERP checks

Helpful docs:

- DataForSEO Labs overview: https://docs.dataforseo.com/v3/dataforseo_labs/overview/
- Google keyword overview: https://docs.dataforseo.com/v3/dataforseo_labs/google/keyword_overview/live/
- Google ranked keywords: https://docs.dataforseo.com/v3/dataforseo_labs/google/ranked_keywords/live/
- Google organic live SERP: https://docs.dataforseo.com/v3/serp/google/organic/live/advanced/

## GitHub

GitHub is the work tracker and review surface.

Use it for:

- SEO tasks as issues
- Labels for work type and priority
- Pull requests for site changes
- Review checklists
- Decision history
- Monthly report archives in private repos

Suggested labels:

- `seo`
- `content`
- `technical-seo`
- `internal-linking`
- `schema`
- `metadata`
- `high-impact`
- `quick-win`
- `needs-data`
- `blocked`
