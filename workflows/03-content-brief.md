# Content Brief Workflow

Use this for a new page, article, landing page, comparison page, or content refresh.

## Inputs

- Target keyword or topic
- Site config
- GSC data for related pages and queries, if available
- DataForSEO keyword and SERP data, if available
- Existing internal pages that should be linked

## Steps

1. Clarify the page type and goal.
2. Validate search intent.
3. Review the SERP shape:
   - Ranking page types
   - Featured snippets or SERP features
   - Common headings
   - Content formats
   - Commercial vs informational signals
4. Check existing site coverage.
5. Create the brief:
   - Primary keyword
   - Secondary keywords
   - Audience
   - Suggested title
   - Suggested meta description
   - URL slug
   - Outline
   - Internal links
   - External facts to verify
   - Schema opportunities
   - Publish checklist
6. Add post-publish verification steps.

## Output

- `outputs/content-brief-[keyword-or-topic].md`

## Done when

- A writer, editor, or site owner can create the page without needing another SEO planning pass.
