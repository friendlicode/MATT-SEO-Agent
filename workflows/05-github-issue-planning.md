# GitHub SEO Issue Planning Workflow

Use this to turn SEO recommendations into trackable GitHub work.

## Inputs

- Any SEO audit, monthly report, content backlog, or technical checklist.
- Repository labels and project board conventions.
- Site config.

## Steps

1. Group recommendations by work type:
   - Content
   - Technical SEO
   - Internal linking
   - Metadata
   - Schema
   - Reporting
2. Assign impact and effort.
3. Create concise issue titles.
4. Include evidence and source links.
5. Add acceptance criteria.
6. Add verification steps.
7. Recommend labels and milestone.

## Issue template

Use `.github/ISSUE_TEMPLATE/seo-task.yml`.

## Done when

- Each recommendation can be assigned, shipped, and verified.
